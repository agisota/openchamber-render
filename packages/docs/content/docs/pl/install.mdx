# Instalacja

Rox Space można uruchomić na trzy sposoby:

- aplikacja na komputer dla macOS
- aplikacja webowa hostowana przez CLI, którą możesz zainstalować jak aplikację na telefonie (jako PWA)
- rozszerzenie do VS Code

## Wymaganie wstępne

Najpierw zainstaluj [OpenCode](https://opencode.ai) — Rox Space działa na jego bazie.

## Przeglądarka + PWA

```bash
curl -fsSL <rox-space-install-script-url> | bash
openchamber --ui-password be-creative-here
```

Otwórz adres URL wypisany przez CLI (zwykle `http://localhost:3000`). Powinna pojawić się lista sesji Rox Space. Aby mieć ją zawsze pod ręką, użyj opcji „Zainstaluj” w pasku adresu przeglądarki, aby dodać ją jako aplikację.

## Komputer

Pobierz najnowszą kompilację na komputer ze strony wydań na GitHubie lub ze strony pobierania Rox Space. Otwórz ją i zaloguj się do swojego zwykłego procesu pracy OpenCode.

## VS Code

Zainstaluj z VS Code Marketplace i zaloguj się do swojego zwykłego procesu pracy OpenCode. Widok Rox Space otworzy się wtedy na pasku bocznym.
